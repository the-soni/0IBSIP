# Number Guessing Game

## About the Project

Number Guessing Game is a simple Java console-based game where the computer generates a random number between 1 and 100. The player has a maximum of 7 attempts to guess the number.

## Features

- Random number generation from 1 to 100
- Maximum 7 attempts
- Too High / Too Low hints
- Correct guess message
- Losing message with the correct number
- Play Again option
- Score tracking

## Technologies Used

- Java
- Random
- Scanner
- Loops
- Conditional Statements
